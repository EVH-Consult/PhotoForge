# Synthetic demo fixture provenance

Every JPEG under `input/` is generated by
`scripts/generate_synthetic_e2e_fixtures.py`. The images are deterministic
geometric drawings and do not depict people, customer material, or real-world
photographs. Their timestamps, camera identity, keywords, and GPS coordinates
are deterministic synthetic values created by that script.

The files under `duplicates/` and `nested/` are byte-for-byte copies used to
exercise duplicate handling. `corrupt.jpg` and `note.txt` are deterministic
non-photo edge cases.

Regenerate the fixture set with:

```console
python scripts/generate_synthetic_e2e_fixtures.py
python scripts/generate_e2e_golden.py --all --write
```
